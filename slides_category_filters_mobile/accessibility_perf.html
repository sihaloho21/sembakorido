Aksesibilitas dan performa adalah bagian dari desain

Standar Aksesibilitas

Semantik & ARIA Gunakan native button dengan aria-pressed="true/false" untuk status terpilih.
Focus Management Indikator fokus yang jelas dan urutan tab yang logis pada rail dan bottom sheet.
Screen Reader Support Label deskriptif seperti "Pilih kategori produk" untuk navigasi rail.

Optimasi Performa

Native Scrolling Gunakan CSS overflow-x dan snap alignment untuk interaksi yang ringan.
Lightweight CSS Prioritaskan CSS transform dan opacity; hindari JS scroll berlebih.
Zero Latency Tidak menambah request API baru; tetap menggunakan data kategori yang sudah ada.
